2. 요약

  • 귀하의 미디어 라이브러리, 자막, 메모 및 학습 기록은 기기에 저장됩니다. 당사는 회원 계정 시스템을 운영하지 않으며 귀하의 학습 데이터를 저장하는 백엔드를 운영하지 않습니다.
  • 당사는 귀하의 개인정보를 판매하지 않으며, 행동 광고 목적으로 사용하지도 않습니다.
  • 본 버전의 앱에는 광고 SDK와 분석 SDK가 포함되어 있지 않습니다.
  • 사진 라이브러리 및 파일 접근은 선택 사항이며 미디어를 가져오거나 내보낼 때에만 사용됩니다. 당사는 카메라, 마이크 또는 위치 정보에 절대 접근하지 않습니다.
  • AI 기능은 귀하가 선택한 텍스트를 직접 설정한 LLM 엔드포인트로 전송합니다 — 제4항을 참조하세요. 기기 내 음성 인식은 기기를 떠나지 않습니다.

  • 파일 / 문서(선택 사항). 로컬 미디어나 문서를 가져올 때 앱은 파일 앱 / '내 iPhone'에서 사용자가 선택한 파일을 읽습니다. 당사가 운영하는 서버로 업로드되는 것은 없습니다.

3.3 기기 외부로 전송되는 정보

다음의 경우에만 해당합니다:

  1. AI 처리. AI 기능(자막 번역, 단어 및 문장 설명, 요약 및 후속 질의응답)을 사용할 때, 사용자가 선택한 텍스트는 설정 → 모델 라이브러리 → LLM 서버에서 직접 설정한 LLM 엔드포인트로 전송됩니다. 수신자는 사용자가 선택한 제공업체이며, 당사는 이를 운영하지 않고, 사용자가 설정한 주소나 키를 읽을 수 없으며, 제출한 내용의 사본도 보관하지 않습니다. 해당 제공업체의 개인정보 처리방침을 검토해 주세요.
  2. 음성 인식(기기 내). 전사는 모델 라이브러리에서 다운로드한 sherpa 모델로 로컬에서 실행됩니다. 오디오와 텍스트는 어디에도 전송되지 않습니다.
  3. 구매 검증. 앱 내 구매는 사용자 기기의 앱 스토어(현재 Apple App Store)에서 검증됩니다. 당사는 구매 확인 정보만 받으며 귀하의 결제 카드 정보는 절대 받지 않습니다.
  4. 원격 구성 및 모델 다운로드. 앱은 개발자의 GitHub Pages / GitHub에서 구성 파일과 기기 내 ASR(sherpa) 모델을 가져옵니다. 이러한 요청에는 귀하의 미디어나 학습 내용이 포함되지 않습니다.

당사는 광고나 분석 SDK를 운영하지 않으므로, 광고 네트워크와 식별자가 공유되지 않습니다.

4. 알기 쉬운 AI 기능 설명

Smart Video는 두 가지 종류의 AI 처리를 제공합니다:

  • 기기 내 음성 인식(ASR): 전사는 사용자가 다운로드한 sherpa 모델로 기기에서 실행됩니다. 사용자의 오디오와 텍스트는 기기를 절대 떠나지 않으며 — 전송되는 것은 없습니다.
  • 사용자 설정 LLM 엔드포인트(BYOK): 번역, 설명 및 요약은 설정 → 모델 라이브러리 → LLM 서버에서 사용자가 직접 입력한 LLM 주소와 키로 선택한 텍스트를 전송하여 생성됩니다. 제공업체는 사용자가 선택하며, 당사는 이를 운영하지도 않고 사용자가 설정한 주소나 키를 읽을 수도 없습니다. 해당 제공업체의 개인정보 및 보관 정책을 검토해 주시고, 기밀이라고 생각되는 정보는 이 경로로 제출하지 마세요.

AI 기능은 설정에서 언제든 끌 수 있으며, 플레이어, 자막 및 로컬 학습 도구는 AI 없이도 계속 작동합니다.

당사는 학습 내용을 모델 학습, 사용자 프로파일링 또는 광고 타게팅에 사용하지 않습니다.
