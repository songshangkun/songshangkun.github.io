2. 要約

  • お客様のメディアライブラリ、字幕、メモおよび学習記録は、すべてお客様のデバイス上に保存されます。当方はアカウントシステムを運用しておらず、お客様の学習データを保存するバックエンドも持っていません。
  • 当方はお客様の個人情報を販売せず、また行動ターゲティング広告に利用することもありません。
  • 本バージョンのアプリには広告 SDK も分析 SDK も含まれていません。
  • フォトライブラリおよびファイルへのアクセスは任意であり、メディアのインポートまたはエクスポート時にのみ使用されます。カメラ、マイク、位置情報へのアクセスは一切行いません。
  • AI機能は、お客様が選択したテキストをお客様自身が設定した LLM エンドポイントに送信します — 第4項をご参照ください。デバイス上での音声認識データがデバイス外に出ることはありません。

3. 取り扱う情報

本アプリはローカルファーストであるため、大部分の情報はデバイス外に出ることがありません。

3.1 デバイス上に保存される情報

対象 目的 保存場所
メディアライブラリの項目：ファイル参照、名称、インポートした URL / HLS リンク、再生位置 学習メディアを再度開いて続きから再生できるようにするため デバイス上のデータベース（アプリのサンドボックス）
字幕ファイルおよび転記キャッシュ 字幕の表示および単語引きを可能にするため デバイス上のデータベース
AI による解説・要約のキャッシュ（単語、文、メディアの要約） AI を再呼び出しせずに過去の結果を表示するため デバイス上のデータベース
単語・フラッシュカードの学習記録および復習スケジュール 間隔反復学習（スペースド・リピティション）による復習を実現するため デバイス上のデータベース
お客様が作成したメモ 学習メモを保持するため デバイス上（メモリ／ローカルストア）
アプリの設定（テーマ、言語、字幕スタイルなど） お客様の設定を記憶するため デバイス上の設定情報
LLM エンドポイントのアドレスおよびキー（設定した場合） 有効化した AI 機能を呼び出すため デバイス上、暗号化して保存；当方は読み取ることができません

当方は上記のサーバー側コピーを一切保持せず、お客様の代わりに復元することもできません。お客様ご自身でバックアップを保存してください。

3.2 特定の機能を利用する場合にのみ取り扱われる情報

  • フォトライブラリ（任意）。 メディアをインポートする際、本アプリはお客様がフォトライブラリから選択した動画・音声を読み取ります。学習素材をエクスポートする際は、本アプリはフォトライブラリに書き込みます。当方がバックグラウンドでライブラリをスキャンすることは一切ありません。この権限を拒否しても、本アプリのそれ以外の機能は引き続き利用できます。
  • ファイル／ドキュメント（任意）。 ローカルのメディアやドキュメントをインポートする際、本アプリは「ファイル」アプリ／「この iPhone 内」からお客様が選択したファイルを読み取ります。当方が運用するサーバーへのアップロードは一切行われません。
  • マイク・カメラ・位置情報は使用しません。 Smart Video はマイク、カメラ、位置情報サービスを要求も利用もしません。音声認識は、インポート済みのメディアファイル内にすでに存在する音声に対して、デバイス上のモデルを用いて実行されます — マイクから録音することは一切ありません。

3.3 デバイス外に送信される情報

以下の場合にのみ送信されます：

  1. AI 処理。 AI 機能（字幕翻訳、単語・文の解説、要約およびフォローアップの質疑応答）を利用する際、お客様が選択したテキストは、設定 → モデルライブラリ → LLM サーバーでお客様自身が設定した LLM エンドポイントに送信されます。受信者はお客様が選択した提供元であり、当方はこれを運用しておらず、設定されたアドレスやキーを読み取ることも、送信内容のコピーを保持することもできません。該当する提供元のプライバシーポリシーをご確認ください。
  2. 音声認識（デバイス上）。 転記は、モデルライブラリでダウンロードした sherpa モデルを用いてローカルで実行されます。音声およびテキストはいかなる場所にも送信されません。
  3. 購入の検証。 アプリ内購入は、お客様のデバイス上のアプリストア（現在は Apple App Store）によって検証されます。当方が受け取るのは購入確認のみであり、お客様のクレジットカード情報を受け取ることは一切ありません。
  4. リモート設定およびモデルのダウンロード。 本アプリは、開発者の GitHub Pages／GitHub から設定ファイルおよびデバイス上 ASR（sherpa）モデルを取得します。これらのリクエストには、お客様のメディアや学習コンテンツは含まれません。

当方は広告や分析の SDK を運用していないため、識別子が広告ネットワークと共有されることはありません。

4. AI 機能をわかりやすく

Smart Video は2種類の AI 処理を提供します：

  • デバイス上の音声認識（ASR）： 転記は、お客様がダウンロードした sherpa モデルを用いてデバイス上で実行されます。お客様の音声およびテキストがデバイス外に出ることはありません — 一切の送信は行われません。
  • ユーザー設定の LLM エンドポイント（BYOK）： 翻訳、解説、要約は、設定 → モデルライブラリ → LLM サーバーでお客様自身が入力した LLM アドレスおよびキーに選択テキストを送信して生成されます。提供元はお客様が選択したものであり、当方はこれを運用しておらず、設定したアドレスやキーを読み取ることもできません。該当する提供元のプライバシーおよび保存ポリシーをご確認いただき、機密とみなす情報はこの経路から送信しないでください。

AI 機能は、設定からいつでも無効にできます。無効にしても、プレーヤー、字幕、およびローカルの学習ツールは AI なしで引き続き利用できます。

5. 情報を処理する理由

当方が情報を処理するのは、お客様のメディアのインポートおよび再生のため、字幕の表示および単語引きのため、ご要望のデバイス上転記の実行のため、設定した AI エンドポイントの呼び出しのため、購入の検証のため、および本アプリの動作とセキュリティの維持のためのみです。

当方は、お客様の学習コンテンツをモデルの学習、プロファイリング、あるいは広告ターゲティングに利用することはありません。

6. 情報を受け取る可能性のある第三者

受信者 受け取る内容 目的
お客様自身が設定した LLM 提供元 翻訳／解説／要約のために送信されたテキスト お客様がリクエストした AI 処理
Apple App Store 購入トークン 購入の検証
GitHub Pages／GitHub（開発者） 設定およびモデルダウンロードのリクエスト（メディアコンテンツを含まず） リモート設定およびデバイス上 ASR モデルの配信

各受信者は独自のプライバシーポリシーの適用を受けます。当方は個人情報を第三者に販売または貸与することはありません。

7. 情報を保持する期間

お客様のライブラリ、字幕、メモおよび学習記録は、お客様がこれらを削除、データを消去、またはアプリをアンインストールするまでデバイス上に残ります。削除またはアンインストールによりこれらは完全に除去され、当方はコピーを保持せず復元もできません。

お客様が設定した LLM 提供元に送信したコンテンツは、当該提供元の保存ポリシーに従って保持されます。

8. セキュリティ

お客様のデータは、デバイス自身のセキュリティ（デバイスのパスコード、ディスク暗号化）によって保護されたローカルデータベースに保存されます。LLM エンドポイントのアドレスおよびキーはデバイス上で暗号化して保存され、当方に送信されることはありません。いかなる保存方法も完全に安全というわけではありませんので、デバイスを保護し、バックアップを保存してください。

9. 児童について

本アプリは児童を対象としていません。当方は、お客様のお住まいの法域におけるデジタル同意年齢（米国では13歳、EEA の大部分では16歳、その他の地域では現地の定める年齢）未満の児童から個人情報を故意に収集することはありません。児童が当方に情報を提供したと思われる場合は、ご連絡いただければ削除のお手伝いをいたします。

お客様の権利はお住まいの地域によります。本書末尾の地域別セクションに詳細を記載しています。いずれの地域であっても、お客様はいつでも以下のことができます：任意の権限を拒否または取り消すこと、アプリ内からデータをエクスポートまたは削除すること、AI 機能の利用を停止すること、あるいはご請求を当方にご連絡すること。

お客様のデータはローカルにあるため、アクセス、訂正、ポータビリティ、削除を行使する最も速やかな方法は、アプリ内で直接行うことです。
