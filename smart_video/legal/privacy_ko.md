### 3.3 기기 외부로 전송되는 정보

다음의 경우에만 해당합니다:

  1. **AI 처리.** AI 기능(자막 번역, 단어 및 문장 설명, 요약 및 후속 질의응답)을 사용할 때, 사용자가 선택한 텍스트는 설정 → 모델 라이브러리 → LLM 서버에서 **직접 설정한 LLM 엔드포인트** 로 전송됩니다. 수신자는 사용자가 선택한 제공업체이며, 당사는 이를 운영하지 않고, 사용자가 설정한 주소나 키를 읽을 수 없으며, 제출한 내용의 사본도 보관하지 않습니다. 해당 제공업체의 개인정보 처리방침을 검토해 주세요.
  2. **음성 인식(기기 내).** 전사는 모델 라이브러리에서 다운로드한 sherpa 모델로 로컬에서 실행됩니다. 오디오와 텍스트는 **어디에도 전송되지 않습니다**.
  3. **구매 검증.** 앱 내 구매는 사용자 기기의 앱 스토어(현재 Apple App Store)에서 검증됩니다. 당사는 구매 확인 정보만 받으며 귀하의 결제 카드 정보는 절대 받지 않습니다.
  4. **원격 구성 및 모델 다운로드.** 앱은 개발자의 GitHub Pages / GitHub에서 구성 파일과 기기 내 ASR(sherpa) 모델을 가져옵니다. 이러한 요청에는 귀하의 미디어나 학습 내용이 포함되지 않습니다.
  5. **선택 진단(사용자가 켤 때만).** 설정에서 "진단 공유"를 활성화하면, 앱은 최대 7일에 한 번씩 최소한의 비개인 스냅샷 — 앱 버전, 운영체제 버전, 기기 언어, 무작위 익명 식별자, 이벤트 유형, 타임스탬프 — 을 수집하고 개발자 메일함으로 주소가 지정된 미리 채워진 이메일 초안을 사용자의 메일 앱에서 엽니다. **아무것도 자동으로 전송되지 않습니다. 이메일은 사용자가 명시적으로 보내기를 탭할 때만 발송됩니다.** 우리는 귀하의 이메일 주소, IP 주소, GPS 위치, 광고 ID, 기기 일련번호 또는 계정 정보를 절대 수집하지 않으며, 이 데이터를 수신하는 서버도 운영하지 않습니다.



당사는 광고나 분석 SDK를 운영하지 않으므로, 광고 네트워크와 식별자가 공유되지 않습니다.

## 4\. 알기 쉬운 AI 기능 설명

Smart Video는 두 가지 종류의 AI 처리를 제공합니다:

  * **기기 내 음성 인식(ASR):** 전사는 사용자가 다운로드한 sherpa 모델로 기기에서 실행됩니다. **사용자의 오디오와 텍스트는 기기를 절대 떠나지 않으며 — 전송되는 것은 없습니다.**
  * **사용자 설정 LLM 엔드포인트(BYOK):** 번역, 설명 및 요약은 설정 → 모델 라이브러리 → LLM 서버에서 **사용자가 직접 입력한 LLM 주소와 키** 로 선택한 텍스트를 전송하여 생성됩니다. 제공업체는 사용자가 선택하며, 당사는 이를 운영하지도 않고 사용자가 설정한 주소나 키를 읽을 수도 없습니다. 해당 제공업체의 개인정보 및 보관 정책을 검토해 주시고, 기밀이라고 생각되는 정보는 이 경로로 제출하지 마세요.



AI 기능은 설정에서 언제든 끌 수 있으며, 플레이어, 자막 및 로컬 학습 도구는 AI 없이도 계속 작동합니다.
