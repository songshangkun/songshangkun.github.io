  • 可选诊断（默认关闭）。 应用在"设置"中提供可选的"共享诊断"开关，默认关闭、需您主动开启。开启后，应用可能生成一份简短、非个人化的诊断报告并协助您通过邮件发送给开发者——见第 3.3 节第 5 条。

3.3 传出设备的信息

仅以下情况：

  1. AI 处理。 使用 AI 功能（字幕翻译、单词与句子解释、总结与追问）时，您选中的文本会被发送到您在"设置 → 模型库 → LLM 服务"中自己配置的 LLM 端点 。接收方是您选择的提供商；我们不运营它，无法读取您配置的地址或密钥，也不保留您提交内容的副本。请查阅该提供商的隐私政策。
  2. 语音识别（设备端）。 转录在设备端用您下载的 sherpa 模型运行。音频与文本不 发送至任何地方。
  3. 购买验证。 应用内购买由设备上的应用商店（当前为 Apple App Store）验证。我们仅收到购买确认，绝不会收到您的支付卡信息。
  4. 远程配置与模型下载。 应用从开发者的 GitHub Pages / GitHub 获取配置文件与设备端 ASR（sherpa）模型。这些请求不包含您的媒体或学习内容。
  5. 可选诊断（仅在您选择开启时）。 若您在"设置"中开启"共享诊断"，应用至多每 7 天会采集一份最小化的非个人快照——应用版本、操作系统版本、设备语言、一个随机匿名标识符、事件类型与时间戳——并在您的邮件应用中打开一封预填好的邮件草稿，收件人为开发者邮箱。任何内容都不会被自动传输：邮件只有在您明确点击发送后才会寄出。 我们绝不收集您的电子邮件地址、IP 地址、GPS 位置、广告标识符、设备序列号或账户信息，也不运营接收此数据的服务器。

我们不运营广告或分析 SDK，因此不会向广告网络共享任何标识符。

4. AI 功能，通俗说明

Watchlingo 提供两类 AI 处理：

  • 设备端语音识别（ASR）： 转录在设备端用您下载的 sherpa 模型运行。您的音频与文本永远不会离开设备——不会传输任何内容。
  • 用户配置的 LLM 端点（BYOK）： 翻译、解释与总结通过把选中文本发送到您在"设置 → 模型库 → LLM 服务"中自行填入的 LLM 地址与密钥 来生成。提供商由您选择——我们不运营它，也无法读取您配置的地址或密钥。请查阅该提供商的隐私与留存政策，不要通过此通道提交您认为机密的信息。

您可以随时在设置中关闭 AI 功能；关闭后播放器、字幕与本地学习工具仍可正常使用。

5. 我们处理信息的原因

我们处理信息仅用于：导入并播放您的媒体；显示字幕并支持查词；运行您请求的本地转录；调用您配置的 AI 端点；验证购买；以及保持应用可用与安全。

我们不会用您的学习内容训练模型、刻画用户画像或定向广告。

7. 信息保留时长
