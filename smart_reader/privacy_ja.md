## 2. 要点

- 読書ライブラリ、読み込んだ文書、メモ、要約、設定は**お使いの端末内**に保存されます。当方はアカウント制度や、読書データを保存するサーバーを運営していません。
- 当方は個人情報を**販売せず**、行動ターゲティング広告にも**利用しません**。
- 本バージョンのアプリには**広告 SDK も解析 SDK も含まれず**、**アプリ内課金もありません**。
- 本アプリは**カメラ・マイク・写真ライブラリ・位置情報の権限を要求しません**。文書や画像はシステムのファイル選択からのみ読み込まれ、文字認識（OCR）は**すべて端末内で実行**されます。
- AI 機能は、あなたが選択したテキストのみを**あなた自身が設定した LLM エンドポイント**へ送信します（第 4 節参照）。

## 3. 当方が取り扱う情報

本アプリはローカル優先のため、ほとんどの情報が端末外に出ません。

### 3.1 端末内に保存される情報

| 内容 | 目的 | 保存場所 |
|---|---|---|
| 読み込んだ文書（PDF・EPUB・Office・テキスト・画像）と抽出したテキスト | 開く・組み替える・再読する | アプリのサンドボックス（アプリケーションサポート） |
| ライブラリ情報：タイトル、形式、読み込み日時、読書位置 | ライブラリ表示と続きからの再開 | 端末内データベース |
| ローカルの全文／検索インデックスと AI 結果キャッシュ（解説・要約・質疑応答） | 文書内検索と AI 呼び出しの重複回避 | 端末内データベースとインデックス領域 |
| 読書・外観設定（テーマ、言語、フォント、ページ送り、クイック操作） | 設定の記憶 | 端末内の設定領域 |
| ダウンロードした音声（TTS）モデル | オフラインでの読み上げ | アプリのサンドボックス（モデル領域） |
| LLM のエンドポイント、モデル名、API キー（設定した場合） | 有効にした AI 機能の呼び出し | 端末内に難読化して保存。当方は読めません |

当方は上記のいかなる内容もサーバー側に保持せず、復元することもできません。ご自身でバックアップしてください。

### 3.2 特定の機能を使うときだけ取り扱う情報

- **ファイル／書類（任意）。** 文書や画像を読み込む際、アプリはシステムのファイル選択であなたが選んだファイルのみを読み取ります。当方が運営するサーバーへのアップロードはありません。
- **端末内の文字認識（OCR）。** 画像やスキャンした PDF ページは、端末内の ML Kit 文字認識コンポーネントによりローカルで認識されます。画像が端末外に出ることはありません。
- **端末内の音声合成（TTS）。** 文書は、ダウンロードしてローカルで実行する音声モデルにより読み上げられます。テキストはどこにも送信されません。
- **マイク・カメラ・位置情報は使用しません。** 本アプリは録音・撮影・位置情報の取得を行いません。

### 3.3 端末外に送信される情報

次の場合に限られます。

1. **AI 処理（任意）。** AI による解説・要約・追加質問・クイック操作を使うと、選択したテキストまたは関連する抜粋が、設定 → AI サービスで**あなた自身が設定した LLM エンドポイント**へ送信されます。受信者はあなたが選んだ提供事業者であり、当方はそれを運営せず、設定されたアドレスやキーを読むことも、送信内容の写しを保持することもできません。当該事業者のプライバシーポリシーをご確認ください。
2. **リモート設定と文書配信。** 本アプリは、開発者の GitHub Pages から設定ファイルと法的文書を、モデルリポジトリ（Hugging Face / hf-mirror）から音声モデルを取得します。これらの通信に、文書の内容・読書履歴・個人識別子は含まれません。
3. **あなたが開始する通信。** 文書内の画像やリンクを開くこと自体で何かがアップロードされることはありません。本アプリには閲覧・追跡・広告のコンポーネントは含まれていません。

## 4. AI 機能のわかりやすい説明

- **利用者が設定する LLM エンドポイント（BYOK）：** 解説・要約・翻訳・質疑応答は、選択したテキストを**あなた自身が入力した LLM のアドレスとキー**へ送信して生成されます。提供事業者はあなたが選ぶものであり、当方は運営せず、設定されたアドレスやキーを読むこともできません。当該事業者のプライバシーと保持の方針をご確認いただき、機密と考える情報はこの経路で送信しないでください。
- **端末内処理：** テキスト抽出、OCR、全文インデックス作成、音声合成はすべて端末内で実行されます。**これらの機能があなたの文書や画像をアップロードすることはありません。**

AI 機能はいつでも無効にできます。無効にしても、閲覧・検索・オフライン読み上げは利用できます。

## 5. 情報を取り扱う理由

当方は、文書の読み込みと表示、テキストの抽出と組み替え、ライブラリの検索・注釈・整理、あなたが要求する端末内 OCR と音声合成の実行、あなたが設定した AI エンドポイントの呼び出し、アプリの可用性と安全性の維持のためにのみ情報を取り扱います。

あなたの文書や読書履歴を、モデルの学習、プロファイリング、ターゲティング広告に利用することはありません。

## 6. 情報を受け取る可能性のある第三者

| 受信者 | 受け取る内容 | 目的 |
|---|---|---|
| あなたが設定した LLM 提供事業者 | 解説・要約・質疑応答のために送信したテキスト | あなたが要求した AI 処理 |
| GitHub Pages / GitHub（開発者） | 設定と法的文書の取得要求（文書内容を含まない） | リモート設定と文書配信 |
| Hugging Face / hf-mirror | 音声モデルのダウンロード要求（文書内容を含まない） | 端末用 TTS モデルの配信 |

各受信者は独自のプライバシーポリシーに従います。当方は個人情報を誰に対しても販売・賃貸しません。

## 7. 情報の保持期間

文書・インデックス・メモ・AI キャッシュ・設定は、あなたが削除するか、ライブラリから文書を削除するか、アプリをアンインストールするまで端末内に残ります。ライブラリから文書を削除すると、そのレコード、元ファイル、インデックス項目が削除されます。アンインストールするとすべてが完全に削除され、当方は写しを保持せず復元できません。

設定した LLM 提供事業者へ送信した内容は、当該事業者の保持方針に従って保持されます。

## 8. セキュリティ

あなたのデータはアプリのサンドボックスに保存され、端末自体のセキュリティ（パスコード、ディスク暗号化）で保護されます。LLM のアドレスとキーは端末内に難読化して保存され、当方へ送信されることはありません。完全に安全な保存方法は存在しないため、端末の保護とバックアップをお願いします。
