## 2. 简而言之

- 您的阅读库、导入的文档、笔记、总结与设置**保存在您的设备上**。我们不运行账号系统，也没有存储您阅读数据的后端。
- 我们**不出售**您的个人信息，也**不**将其用于行为广告。
- 本版本应用**不含广告 SDK 与分析 SDK**，**没有应用内购买**。
- 本应用**仅申请麦克风权限**，且只用于可选的语音输入与笔记录音——音频由**端侧流式语音识别模型在本机转成文字**，绝不上传；相机、相册与定位权限均不申请。文档与图片仅通过系统文件选择器导入，文字识别（OCR）**完全在本机运行**。
- AI 功能在**您自己配置的 LLM 端点**上运行，或使用**您下载到本机的端侧模型**——见第 4 节。

## 3. 我们处理的信息

由于本应用是本地优先的，绝大多数信息不会离开您的设备。

### 3.1 存储在设备上的信息

| 内容 | 用途 | 留存位置 |
|---|---|---|
| 导入的文档（PDF、EPUB、Office、文本、图片）及其提取出的文字 | 打开、重排并再次阅读 | 应用沙盒（应用支持目录） |
| 阅读库记录：标题、格式、导入时间、阅读进度 | 展示阅读库并从上次位置继续 | 设备数据库 |
| 本地全文 / 检索索引与 AI 结果缓存（解释、总结、问答） | 搜索文档并避免重复调用 AI | 设备数据库与索引目录 |
| 阅读与外观设置（主题、语言、字体、翻页方式、快捷操作） | 记住您的偏好 | 设备偏好 |
| 已下载的语音（TTS）模型 | 离线朗读文档 | 应用沙盒（模型目录） |
| LLM 端点地址、模型名与 API Key（若您配置） | 调用您启用的 AI 功能 | 设备端，以混淆形式存储；我们无法读取 |
| 已下载的语音识别（ASR）、端侧 LLM 与 Embedding 模型 | 语音输入、离线问答与语义检索 | 应用沙盒（模型目录） |
| 笔记录音、对话记录、总结与共享笔记 | 回放录音并继续学习 | 设备数据库与应用沙盒 |

我们不在服务端保留上述任何内容的副本，也无法为您恢复。请自行备份。

### 3.2 仅在您使用特定功能时处理的信息

- **文件 / 文稿（可选）。** 导入文档或图片时，应用只读取您在系统文件选择器中选中的文件。不会上传到我们运营的服务器。
- **本机文字识别（OCR）。** 图片与扫描版 PDF 页面由设备端的 ML Kit 文字识别组件在本地识别。图片绝不离开您的设备。
- **本机语音合成（TTS）。** 文档由您下载并运行在本机的语音模型朗读，文本不会发送到任何地方。
- **语音输入与笔记录音（可选）。** 当您口述文字或为笔记添加录音时，应用会使用麦克风与**完全在设备端运行**的流式语音识别模型。音频仅在本机转成文字，不会上传。您可以拒绝麦克风权限，阅读、AI 等其他功能仍可正常使用。
- **端侧模型（可选）。** 您可以下载语音识别、语音合成、Embedding 与小型语言模型（GGUF）。这些文件保存在应用沙盒中并在本机运行，您的文字与音频不会发送给我们或模型提供方。

### 3.3 传出设备的信息

仅以下情况：

1. **AI 处理（可选）。** 使用 AI 解释、总结、追问或快捷操作时，您选中的文本或相关片段会被发送到您在"设置 → AI 服务"中**自己配置的 LLM 端点**。接收方是您选择的提供商；我们不运营它，无法读取您配置的地址或密钥，也不保留您提交内容的副本。请查阅该提供商的隐私政策。
2. **远程配置与文档分发。** 应用从开发者的 GitHub Pages 获取配置文件、法律文档与可选的应用推荐列表，并从模型仓库（Hugging Face / hf-mirror）下载语音、语音识别、Embedding 与端侧语言模型。这些请求不包含您的文档内容、阅读历史、音频或个人标识。
3. **由您发起的网络访问。** 在文档内打开图片或链接本身不会上传任何内容；应用不包含浏览、追踪或广告组件。

## 4. AI 功能，通俗说明

- **用户配置的 LLM 端点（BYOK）：** 解释、总结、翻译与问答通过把选中文本发送到您在设置中**自行填入的 LLM 地址与密钥**来生成。提供商由您选择——我们不运营它，也无法读取您配置的地址或密钥。请查阅该提供商的隐私与留存政策，不要通过此通道提交您认为机密的信息。
- **端侧 LLM 模型（可选）：** 解释、总结与问答也可由您下载并在本机运行的小型 GGUF 模型生成。此模式下文本始终留在设备上，不会发送到任何地方。
- **本机处理：** 文字提取、OCR、全文与语义索引、语音合成、语音识别与端侧模型推理都运行在您的设备本地。**这些功能不会上传您的文档、图片或音频。**

您可以随时关闭 AI 功能；关闭后阅读、搜索与离线朗读仍可正常使用。

## 5. 我们处理信息的原因

我们处理信息仅用于：导入并展示您的文档；提取与重排文字；让您搜索、批注与整理阅读库；运行您请求的本机 OCR 与语音合成；调用您配置的 AI 端点；以及保持应用可用与安全。

我们不会用您的文档或阅读历史训练模型、刻画用户画像或定向广告。

## 7. 信息保留时长

您的文档、索引、批注、AI 缓存与设置在设备上保留，直到您删除它们、从阅读库删除该文档或卸载应用。从阅读库删除文档会移除其记录、原始文件与索引条目。卸载会永久移除全部数据；我们不保留副本且无法恢复。

您提交给所配置 LLM 提供商的内容按其留存政策保留。

## 8. 安全

您的数据存储在应用沙盒中，受设备自身安全（设备密码、磁盘加密）保护。LLM 端点地址与密钥在设备端以混淆形式存储，绝不传输给我们。没有绝对安全的存储方式，请保护好您的设备并自行备份。

## 9. 儿童

本应用不面向儿童。我们不会明知而收集未满所在司法辖区数字同意年龄儿童的个人信息（美国为 13 岁，欧洲经济区多数为 16 岁，其他地方依当地规定）。若您认为有儿童向我们提供了信息，请联系我们，我们将协助删除。

由于您的数据在本地，行使访问、更正、可携或删除权的最快方式是在应用内直接操作。
