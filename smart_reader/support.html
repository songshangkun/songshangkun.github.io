Frequently Asked Questions

How do I import a document?

Open the app → Library → + (Import) and pick one or more files with the system file picker. Supported formats are PDF, EPUB, DOCX, PPTX, XLSX, TXT, Markdown, HTML, CSV and images (PNG, JPG, JPEG, GIF, WEBP, BMP). Imported files and their extracted text stay on your device and are never uploaded to a server we operate.

A document will not open or looks incomplete.

The app has safety limits per document: up to 200 pages and 30,000 elements. Password-protected or damaged PDFs cannot be parsed. Scanned PDFs and images are processed with on-device OCR (ML Kit), so the text layer depends on image quality. Very large or unusual files may hit the element limit; splitting the document usually helps.

How do I set up the AI features (explain, translate, summarise, Q&A)?

Open Settings → AI Service → LLM Settings. You have two options:

  • Your own LLM endpoint (BYOK) — enter an OpenAI-compatible address, model name and API key. The provider is chosen by you; we do not operate it and cannot read your address or key.
  • On-device model (GGUF) — download a small model and run it locally. No text leaves the device, but the model needs enough free memory on your phone.

If neither is configured, AI actions stay disabled; reading, search, OCR and speech still work.

The AI features are not responding, or the app says the model is too large.

For a BYOK endpoint: check the address, model name and API key in Settings → AI Service → LLM Settings, and make sure the device has network access. For an on-device model: close other apps, choose a smaller model, or switch to a BYOK endpoint. The app may warn you when free memory is low; you can still choose to force-load the model at your own risk. Still stuck? Email us with the exact error message.

Voice input or note recording does not work.

First download a speech-recognition model in Settings → AI Service → Speech Models. Then allow microphone access when the system asks. The microphone is used only while you dictate text or attach a recording to a note; audio is transcribed on your device and is never uploaded. If you decline the microphone permission, all other features keep working.

How do I listen to a document (text-to-speech)?

No TTS model is bundled with the app. Open Settings → AI Service → TTS Models, download a voice model (for example Kitten Nano for English or Kokoro for English and Chinese), then select it. Reading aloud runs entirely on your device and works offline.

Model downloads are slow or fail.

Models are downloaded from the model repository (Hugging Face, or the hf-mirror mirror in mainland China). Check your network and free storage, then retry from the model page. Downloads can be resumed; partial files are kept until the download completes or you delete the model.

Where is my data stored? Can I back it up?

Your library, imported files, notes, summaries, chat history, recordings and settings are stored on your device. We run no account system and keep no server-side copy. Uninstalling the app removes this data, so keep your own backups of the original documents and any notes you need.

Does the app collect data, show ads or use analytics?

No. This version contains no ads and no third-party analytics SDK. Pro is a one-time purchase handled by the App Store; there are no subscriptions. The only outbound requests are: optional AI calls to the endpoint you configure, fetching remote configuration and legal documents from the developer's GitHub Pages, downloading models from Hugging Face / hf-mirror, and loading the optional app-recommendation list. None of these requests include your document content. See our Privacy Policy for details.

How do I change the language, theme or reading font?

Open Settings → Reading & Interface. The app supports eight interface languages (English, 简体中文, Deutsch, Español, Français, Italiano, 日本語, 한국어), light / dark / system themes, paper presets and six font-size steps. Page numbers and AI citations use the same page projection, so they stay consistent when you change the font size.

The app is in the wrong language or a feature is missing.

Some features depend on downloaded components: OCR (ML Kit), on-device speech recognition, TTS voices, the embedding model and optional LLM models. Check Settings → AI Service for the status of each component, then retry the download. If a feature is still unavailable, email us with the screen name.
