2. 요약

  • 당사는 귀하의 개인정보를 판매하지 않으며 행동 기반 광고에 사용하지 않습니다.

  • 앱은 카메라, 마이크, 사진 라이브러리, 위치 권한을 요청하지 않습니다. 문서와 이미지는 시스템 파일 선택기를 통해서만 가져오며, 문자 인식(OCR)은 전적으로 기기에서 실행됩니다.

3.2 특정 기능을 사용할 때만 처리하는 정보

  • 파일/문서(선택). 문서나 이미지를 가져올 때 앱은 시스템 파일 선택기에서 귀하가 선택한 파일만 읽습니다. 당사가 운영하는 서버로 업로드되지 않습니다.
  • 기기 내 문자 인식(OCR). 이미지와 스캔한 PDF 페이지는 기기의 ML Kit 문자 인식 구성 요소로 로컬에서 인식됩니다. 이미지는 기기 밖으로 나가지 않습니다.
  • 기기 내 음성 합성(TTS). 문서는 귀하가 다운로드하여 기기에서 실행하는 음성 모델로 읽어 줍니다. 텍스트는 어디에도 전송되지 않습니다.
  • 마이크, 카메라, 위치 없음. 앱은 오디오를 녹음하거나 사진을 찍거나 위치를 요청하지 않습니다.

3.3 기기 밖으로 나가는 정보

다음 경우에만 나갑니다.

  1. AI 처리(선택). AI 설명, 요약, 추가 질문 또는 빠른 작업을 사용하면 선택한 텍스트 또는 관련 발췌가 설정 → AI 서비스에서 귀하가 직접 설정한 LLM 엔드포인트로 전송됩니다. 수신자는 귀하가 선택한 제공업체이며, 당사는 이를 운영하지 않고 설정한 주소나 키를 읽거나 제출 내용의 사본을 보관할 수 없습니다. 해당 제공업체의 개인정보 처리방침을 확인해 주세요.

  3. 귀하가 시작한 네트워크 접근. 문서 안의 이미지나 링크를 여는 것 자체로는 무엇도 업로드되지 않습니다. 앱에는 탐색, 추적 또는 광고 구성 요소가 포함되지 않습니다.

4. AI 기능, 알기 쉽게

  • 사용자 설정 LLM 엔드포인트(BYOK): 설명, 요약, 번역, 질의응답은 선택한 텍스트를 귀하가 직접 입력한 LLM 주소와 키로 전송하여 생성됩니다. 제공업체는 귀하가 선택하며, 당사는 운영하지 않고 설정한 주소나 키를 읽을 수 없습니다. 해당 제공업체의 개인정보 및 보존 정책을 확인하고, 기밀이라고 생각하는 정보는 이 경로로 제출하지 마세요.
  • 기기 내 처리: 텍스트 추출, OCR, 전체 텍스트 인덱싱 및 음성 합성은 모두 기기에서 실행됩니다. 이 기능들은 귀하의 문서나 이미지를 업로드하지 않습니다.

AI 기능은 언제든 끌 수 있으며, 끄면 읽기, 검색, 오프라인 읽어 주기는 계속 작동합니다.

귀하의 문서나 읽기 기록을 모델 학습, 프로파일링 또는 표적 광고에 사용하지 않습니다.

설정한 LLM 제공업체에 제출한 내용은 해당 제공업체의 보존 정책에 따라 보관됩니다.

8. 보안

귀하의 데이터는 앱 샌드박스에 저장되며 기기 자체의 보안(기기 암호, 디스크 암호화)으로 보호됩니다. LLM 주소와 키는 기기에 난독화하여 저장되며 당사로 전송되지 않습니다. 완벽하게 안전한 저장 방법은 없으므로 기기를 보호하고 백업해 주세요.

10. 귀하의 권리

권리는 거주 지역에 따라 다릅니다. 어디에 있든 언제든지 선택 권한을 거부·철회하고, 앱에서 문서와 데이터를 삭제하고, AI 기능 사용을 중단하고, 당사에 요청할 수 있습니다.

데이터가 기기에 있으므로 접근, 정정, 이동, 삭제 권리를 행사하는 가장 빠른 방법은 앱 안에서 직접 조작하는 것입니다.
